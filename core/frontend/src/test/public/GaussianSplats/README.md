# Gaussian splat interoperability fixture

`cesium-cube.glb` is the unmodified `sh_unit_cube/0/0.glb` fixture from
[CesiumJS 1.146](https://github.com/CesiumGS/cesium/blob/1.146/Specs/Data/Cesium3DTiles/GaussianSplats/sh_unit_cube/0/0.glb).
It contains 27 SPZ v3 compressed splats and spherical harmonics through degree 3 using Cesium's established draft metadata profile and the extension name `KHR_gaussian_splatting_compression_spz_2`.
